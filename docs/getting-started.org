* Install
:PROPERTIES:
:CUSTOM_ID: install
:END:

Veritas is a Guile library, so Guile 3.0 and its fibers are what it needs.  It
ships in Guix, in the AUR, as an openSUSE package and as a Debian package; the
[[file:../README.org][README]] lists the one-line commands for each.  From a checkout:

#+begin_src sh
guix shell -D -f default.nix
./bin/veritas --version
#+end_src

* A first test
:PROPERTIES:
:CUSTOM_ID: a-first-test
:END:

A test file is a module that exports a procedure; veritas calls it to get the
tests.  Nothing is run at import time.

#+begin_src scheme
(define-module (tests arithmetic)
  #:use-module (veritas veritas)
  #:export (spec))

(define (spec)
  (test "two and two"
        (assert-equal #:expect 4 #:got (+ 2 2)))
  (suite "strings"
         (test "concatenation"
               (assert-equal #:expect "ab" #:got (string-append "a" "b")))))
#+end_src

* Run it
:PROPERTIES:
:CUSTOM_ID: run-it
:END:

#+begin_src sh
veritas test/tests/arithmetic.scm
#+end_src

Every runner takes a file, a directory, or nothing (the current directory), and
finds the test files itself.  The default reporter prints one line per failure
and a summary; [[file:reporting.org][Reports and diagnostics]] explains the others.

* Environment variables
:PROPERTIES:
:CUSTOM_ID: environment
:END:

The runner is configured by the environment when no flag says otherwise:

| Variable                    | Meaning                                       |
|-----------------------------+-----------------------------------------------|
| =VERITAS_SCAN_DIR=          | root the run walks (default =./=)             |
| =VERITAS_TEST_TOP_DIR=      | subdirectory holding the suites (default =test=) |
| =VERITAS_TEST_MODULE=       | module prefix under the test root (default =veritas=) |
| =VERITAS_TEST_TYPE=         | =unit=, =integration=, and so on: which directory is read |
| =VERITAS_ENTRYPOINT=        | no-argument procedure each file exports (default =spec=) |
| =VERITAS_ONLY_TEST=         | run only tests whose name contains the value  |
| =VERITAS_ONLY_SUITE=        | run only suites whose name contains the value |
| =VERITAS_ONLY_TAG=          | run only tests and suites carrying the tag    |
| =VERITAS_ONLY_FAILED=       | =true= reruns only the tests the last run recorded as failing |
| =VERITAS_LAST_FAILED_PATH=  | where that record is kept (default =reports/last-failed.scm=) |
| =VERITAS_SEED=              | seed for shuffling, so an order can be replayed |
| =VERITAS_SHUFFLE_FILES=     | =true= shuffles the test files themselves     |
| =VERITAS_JOBS=              | run the files in N worker processes (default =1=) |
| =VERITAS_PARTITION=         | =INDEX/TOTAL=: run one slice of the discovered files |
| =VERITAS_RETRIES=           | extra attempts for a failing test (default =0=) |
| =VERITAS_CHANGED=           | =true= runs only the tests the working tree change reaches |
| =VERITAS_SINCE=             | revision the change is read against, e.g. =origin/trunk= |
| =VERITAS_SRC_DIR=           | source root of the change graph (default =src=) |
| =VERITAS_COVERAGE=          | =true= measures coverage                      |
| =VERITAS_COVERAGE_DIR=      | where the LCOV report goes (default =reports/lcov=) |
| =VERITAS_COVERAGE_HTML_DIR= | where the HTML report goes (default =reports/html=) |
| =VERITAS_REPORTER=          | =emoji-reporter=, =monotone-reporter=, =json-reporter=, =junit-reporter= or =github-reporter= |
| =VERITAS_JUNIT_PATH=        | where the JUnit document goes (default =reports/junit/veritas-junit.xml=) |
| =VERITAS_TRACE=             | =true= records every step of the run to =reports/traces= |
| =VERITAS_LIST=              | =true= prints the selected test files and runs none |
| =VERITAS_RUN_BENCHMARKS=    | =false= skips =benchmark= forms               |

The command line wins over every one of them, =veritas --help= lists the flags
they map to, and the [[file:../man/veritas.1][man page]] has the details.
[[file:running.org][Running tests]] explains what the selection and ordering ones do, and
[[file:running.org][Running tests]]'s *Rerunning only what failed* section covers
=VERITAS_ONLY_FAILED= and =VERITAS_LAST_FAILED_PATH=.
