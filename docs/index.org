* Veritas documentation

Veritas is a test framework for Guile Scheme.  These documents go past the
[[file:../README.org][README]]'s quick start and explain how each part works, what it
guarantees, and where its seams are.

** Where to start

If you have never run veritas, read [[file:getting-started.org][Getting started]].
If you are upgrading a project that already uses it, read
[[file:migration.org][Migration guide]] first: 1.0 changes the default order in
which a suite runs its tests.

If your suite has grown past the point where running all of it is cheap, read
[[file:incremental.org][Change-aware runs]]: =veritas --changed= runs only what
the diff can reach.  When a run fails and the report is not enough, read
[[file:debugging.org][Debugging a run]]; to rerun just the tests that failed, read the
*Rerunning only what failed* section of [[file:running.org][Running tests]].
